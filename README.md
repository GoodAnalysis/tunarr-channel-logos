# Tunarr channel logos

Channel logos for Kyle's Tunarr channels, hosted here so Plex clients
(Apple TV via the server proxy, iPhone directly) can load them from anywhere.
Each channel's icon in Tunarr points at the file's raw URL:

    https://raw.githubusercontent.com/GoodAnalysis/tunarr-channel-logos/main/<file>
